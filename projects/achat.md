# Achat 项目速览

## 基本信息

- **产品**：语音社交/约会 App（Android + iOS）
- **市场**：印度、孟加拉、巴基斯坦、沙特等
- **当前版本**：3.22
- **产品经理**：胡丝淇

## 技术概要

- 客户端：iOS / Android，同一套代码
- 服务端：Go（proto 定义接口），HTTP + PB 推送
- 钱包：钻石(diamond)、金币(coin)、宝石(gem)、魅力值(charisma)，3.22 新增高级代币
- 支付：SKU 充值（GooglePay/PhonePe），支持补单/对账

## 服务架构

```
一套客户端代码
    ├── Achat 主服          ← 独立服务端
    └── Anplay              ← 独立服务端（冷启动期）
        ├── S1              ← 分服：不同人群
        ├── S2
        └── S3
```

- **客户端代码共享**：通过判断逻辑走不同服务的展示方案
- **需求关注点**：注意需求是否需要开放全部服务端 / 指定服务端 / 指定分服开启
- **MCP 项目 ID**：1 · **用例库 ID**：17（Achat用例库）

## 关键业务概念

- **爵位系统**：用户付费等级，影响权益和展示
- **VIP 成长**：消费累计升级，3.22 支持代币充值计入
- **亲密度**：用户间互动等级，3.22 新增兑换商城
- **礼物面板**：多货币结算（钻石/代币/金币），支持分 TAB
- **审核状态**：特定市场需隐藏部分功能（参考 ChaloTalk 审核策略）
