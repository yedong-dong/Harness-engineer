# HalaMe 项目速览

## 基本信息

- **产品**：社交/语音 App
- **平台**：iOS + Android
- **当前版本**：2.18.00
- **与 Achat 关系**：完全独立（客户端和服务端均独立）
- **审核体系**：有审核模式（A面/B面），审核开关开启时服务端屏蔽特定房间类型

## 技术概要

- 服务端：common config 控制动态配置
- OMS 后台：可视化配置管理（商城Tab、背包Tab）
- 基建：channel-gp / channel / activation 三SDK归因体系
- UNO：独立游戏模式，通过 roomType 区分
