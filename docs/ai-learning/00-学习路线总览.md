# AI 工程化技术学习路线总览

> 基于 polebug 的分享 + 本项目已有实践的融合讲解

## 学习地图

```
AI 工程化技术全景

第一层：Agent 核心技术（AI 怎么「做事」）
├── Tool Calling    → 让 AI 调用外部工具（函数、API）
├── Agent Workflow  → 编排多步骤、有状态的执行流程
├── Persistence     → 保存状态，让 Agent 断点续跑
└── Memory          → 短期记忆（当前对话）vs 长期记忆（跨会话）

第二层：AI 工程化落地（AI 怎么「落地」）
├── Prompt 工程     → 写出稳定、可复用的提示词
├── Skill 工程      → 封装知识+流程+工具为可复用单元
├── MCP Server      → 把系统能力包装成 AI 可发现的工具
├── RAG             → 让 AI 检索内部知识再回答
└── Eval 评测       → 衡量 Prompt/Skill 的质量，持续优化

第三层：工作方式转变（人怎么「转型」）
├── 从使用者 → 构建者：不只是用 AI 工具，而是构建 AI 工具链
├── 从单岗 → 跨岗：AI 团队需要理解所有业务线的痛点和流程
└── 从执行者 → 策略者：AI 做执行，人做判断和优化
```

## 推荐学习顺序

```
第一周：Tool Calling + MCP Server（夯实底层理解）
  ↓
第二周：Agent Workflow（系统化你已有的分散知识）
  ↓
第三周：RAG（开拓新领域）
  ↓
第四周：Prompt/Skill + Eval（把你已有的实践理论化、可迁移）
```

每个模块包含三部分：**原理讲解** → **与你已有知识的连接** → **练习题+答案**。
