# 全链路 Pipeline

```
  ┌─────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────┐   ┌──────┐
  │  PRD    │   │  分析     │   │  生成     │   │  评估     │   │  导出     │   │ 导入  │   │ 平台  │
  │  文字    │──→│  澄清     │──→│  并行     │──→│  分离     │──→│  .xmind  │──→│ 分批  │──→│  入库  │
  └─────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────┘   └──────┘
       │             │               │               │               │              │           │
       ▼             ▼               ▼               ▼               ▼              ▼           ▼
  · PRD 文档    · 四维提取     · Fan-out      · 独立上下文     · 格式化输出    · 解析 .xmind  · 用例库节点
  · 技术文档    · 交叉校验     · N 个 Agent    · 5 维度评分     · 覆盖统计      · 选项目/库    · 批量写入
  · UI 截图     · 澄清问题     · 并行执行      · 回修循环       · workflow.md   · 分批导入     · 树缓存刷新
                · ★ 暂停确认   · Fan-in 汇合   · 最多 3 轮                     · MCP 调用
```

## 阶段详解

```
  ═══════════════════════════════════════════════════════════════
  阶段          输入              输出              人工介入
  ═══════════════════════════════════════════════════════════════
  1 分析澄清    PRD + 技术文档    澄清问题 + 假设     ★ 暂停确认
  2 并行生成    确认决策 + 约束    /tmp/cases_*.json  无（全自动）
  2.5 评估      合并后 cases.json 评分 + 回修提示     无（全自动）
  3 导出        cases.json        .xmind             无（全自动）
  （可选）导入   .xmind            平台用例节点        确认目录名
  ═══════════════════════════════════════════════════════════════
```

## 人工节点设计

```
  全流程仅 2 个人工节点：

  1. 阶段 1 末尾 —— 澄清确认
     用户看分析结果 + 澄清问题，自然回复
     无命令词，有补充就说，没问题直接过

  2. 导入前 —— 确认目标路径
     选项目 → 选用例库 → 命名目录
     其余全自动
```
