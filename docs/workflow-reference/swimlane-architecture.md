# 泳道架构：三层分离

```
  ┌──────────────────────────────────────────────────────────────────┐
  │ 调度层（主 Agent）                                                │
  │                                                                  │
  │   PRD + 技术文档                                                 │
  │       │                                                          │
  │       ├─ 四维提取：Feature / Rule / State / Risk                 │
  │       ├─ 交叉校验：PRD ↔ 技术文档差异                            │
  │       ├─ 澄清决策：暂停 → 用户确认 → 带入下游                     │
  │       │                                                          │
  │       ├─ 模块拆分（负载均衡）                                     │
  │       │                                                          │
  │       │   ★ 同一条消息并行派发 N 个 SubAgent                      │
  │       │                                                          │
  │       └─ 收集 /tmp/cases_*.json → 合并去重 → cases.json          │
  │                                                                  │
  └──────────────────────────┬───────────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │ 执行层（SubAgent 池）                                             │
  │                                                                  │
  │   SubAgent-1    SubAgent-2    SubAgent-3    ...    SubAgent-N    │
  │   ──────────    ──────────    ──────────           ──────────    │
  │   模块A · 8条   模块B · 11条  模块C1 · 9条         模块N · N条   │
  │       │              │              │                   │        │
  │       └──────────────┴──────────────┴───────────────────┘        │
  │                          │                                       │
  │                /tmp/cases_*.json                                  │
  │                                                                  │
  │   每个 SubAgent 收到：PRD片段 + 技术摘要 + 约束 + 确认决策        │
  │   互不依赖，完全并行                                              │
  │                                                                  │
  └──────────────────────────┬───────────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │ 质控层（Evaluator SubAgent）                                      │
  │                                                                  │
  │   输入：PRD 全文 + cases.json                                     │
  │   ★ 上下文隔离：不接触生成过程                                    │
  │                                                                  │
  │   5 维度评分                                                      │
  │   ┌────────────┬──────────┬──────┐                                │
  │   │ 功能覆盖    │ ≥ 80%    │ 最高  │                               │
  │   ├────────────┼──────────┼──────┤                                │
  │   │ 规则覆盖    │ ≥ 80%    │ 高    │                               │
  │   ├────────────┼──────────┼──────┤                                │
  │   │ 边界/异常   │ ≥ 60%    │ 中    │                               │
  │   ├────────────┼──────────┼──────┤                                │
  │   │ 优先级分布  │ ≥ 70%    │ 中    │                               │
  │   ├────────────┼──────────┼──────┤                                │
  │   │ 可执行性    │ ≥ 80%    │ 低    │                               │
  │   └────────────┴──────────┴──────┘                                │
  │                                                                  │
  │   全通过 ✓ → 放行到导出                                           │
  │   不通过 ✗ → regenerate_hint → 调度层回修 → 重新评估              │
  │                                                                  │
  └──────────────────────────┬───────────────────────────────────────┘
                             │
                             ▼
                        .xmind 导出
                      平台导入（可选）
```

## 各层职责

```
  调度层           执行层             质控层
  ═══════         ═══════           ═══════
  做什么           怎么做             做得对吗
  拆解 + 派发      写用例             验证质量
  1 个 Agent       N 个 Agent        1 个 Agent
  串行             并行               串行
```

## 为什么三层分离

```
  · 调度层不写用例 → 上下文干净，专注拆解和决策
  · 执行层各自独立 → 模块上下文集中，不互相干扰
  · 质控层盲评     → 不受生成过程影响，客观判断
```
