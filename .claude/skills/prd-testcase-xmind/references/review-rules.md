# Review Rules

## 唯一 Review 阶段：澄清确认

Agent 分析完 PRD 后，必须暂停并展示澄清结果，等待用户回复。

## 回复处理（无命令词）

用户只需自然回复，Agent 根据语义判断：

- **默认行为（pass with notes）**：用户说了任何话，只要不是明确要求重来/修改，就视为确认通过。用户回复中的补充信息、纠正、额外要求，全部作为备注带入生成阶段。

- **需要重来**：用户明确表达了否定意图（如"不对"、"重新分析"、"这里搞错了"、"换个思路"）。Agent 记录反馈，修正后重新展示澄清结果，再次等待确认。

## 展示要求

Agent 必须同时展示：

- 已纳入的测试范围（模块/功能维度）
- 澄清问题列表（每项附带默认假设）
- 已识别的风险点
- 提示：直接回复即可，无需特定命令词。有补充就说，没问题就直接确认。

## 推荐展示模板

```
当前已完成 PRD 分析，请你确认：

**已纳入范围：**
- ...

**澄清问题：**
| # | 问题 | 默认假设 |
|---|------|----------|
| 1 | ... | ... |

**风险点：**
- ...

直接回复你的想法——有补充就补充，没问题我就继续生成。
```

## 用户补充信息处理

用户在回复中补充的所有信息（纠正、补充场景、额外注意点），Agent 必须完整带入 XMind 生成阶段。
