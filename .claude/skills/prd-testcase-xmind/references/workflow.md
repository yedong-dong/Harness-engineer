# Workflow

## 工作流目标

从用户提供的 PRD 文字出发，经历「合并分析(含技术文档+交叉校验) + 澄清 → Subagent 并行生成 → 合并导出」流程，产出 `.xmind` 脑图。

技术文档鼓励与 PRD 同时提供。没有技术文档时跳过交叉校验，其余流程不变。

## 工作流规则

1. Agent 是唯一决策者——只派 Subagent 并行生成用例，不派 Subagent 做分析
2. 阶段 1 同步读取 PRD + 技术文档，暂停等待用户确认，不能自动跳过
3. 用户确认后才能进入阶段 2（Subagent 并行生成）
4. 阶段 2 启动后一次性完成：Subagent 并行生成 → 主 Agent 合并 → 覆盖自检 → 导出 XMind
5. 中间产物不落盘
6. 最终交付物仅为 `.xmind` 文件

## 标准时序

1. 用户提供 PRD 文字 + 技术文档（鼓励同时提供）
2. Agent 同步读取 PRD + 技术文档 → 下载并识别文中图片 → 提取测试维度 → 执行交叉校验 → 列出澄清问题 + 默认假设
3. **暂停**，等待用户回复（自然回复即可，无命令词。差异点一并决策）
4. 用户确认后，提取约束限制 → 按模块拆分 → Subagent 并行生成（携带约束+技术摘要）
5. 主 Agent 合并 → 去重 → 覆盖自检（遗漏并行补 case） → export_xmind.py 导出 XMind → 生成 workflow.md
6. Agent 生成 `workflow.md` + 汇报 `.xmind` 路径 + 覆盖统计

## 技术文档分级提取规则

- 技术文档与 PRD 在阶段 1 同步读取，不延后处理
- 主 Agent 只读一次技术文档，不把全文分发给 Subagent
- ✅ **允许提取**：状态机定义（枚举值/状态路径）、key 维度（缓存/锁/冷却）、唯一性构造规则、错误码与触发条件、双人/单人差异、边界数值
- ✗ **仍然禁止**：Proto 文件路径/generated code、import 依赖、代码文件路径/模块名、具体 Redis 命令（HMSet/Expire）
- 按模块裁剪后，将相关摘要 + 交叉校验差异作为 Subagent 的"技术补充"输入

## 图片识别规则（阶段 1）

- 扫描 PRD 和技术文档中所有图片 URL（`![](url)` 格式 + Mermaid SVG 外链）
- 使用 `curl` 并行下载到 `/tmp/skill_images/` 临时目录（`&` + `wait`）
- 使用 `Read` 工具识别图片内容，提取测试相关视觉信息：
  - **UI 原型图/交互稿**：页面布局、按钮位置与文案、弹窗样式、列表排序规则、不同状态下的展示差异
  - **流程图/Mermaid 图**：完整状态路径、分支条件、串并行步骤、异常分支
  - **表格截图**（含文字）：字段名、枚举值、约束条件
- 图片描述融入四维分析，特别是 Feature（交互细节）和 State（状态流转）
- **模型差异**：Claude 模型正常识别；非 Claude 模型（Deepseek 等）Read 返回 `[Unsupported Image]`，此时记录图片 URL + 元数据，标注无法识别，不阻塞流程
- 识别完成后删除临时文件
- 图片下载失败同样不阻塞流程，标注"图片下载失败"继续

## 交叉校验规则（阶段 1）

- 系统比对 PRD 与技术文档，识别以下差异并列为澄清问题：
  - 状态语义不一致（如 PRD 命名 vs 技术状态码）
  - 维度差异（如 PRD 描述的关键维度在技术上存在额外维度）
  - 隐含约束（技术实现引入的、PRD 未明确的限制）
- 每项差异附带默认假设，用户确认时一并决策
- 交叉校验差异表同步落盘到 `需求信息.md`

## 澄清阶段规则

- Agent 必须列出足够具体的澄清问题，每项附带默认假设
- 问题聚焦业务决策：等级节点、关系互斥规则、撤回范围、异常处理策略等
- 交叉校验发现的差异点直接列为澄清问题
- 不要求用户确认用例细节，只确认影响测试范围的高层决策
- **约束提取**：用户确认时可附加测试范围约束（如"只测功能阶段，浏览器兼容不纳入"），Agent 自动从回复中提取限制性语句（`不测XX`、`只测XX`、`XX不纳入`），汇总后在阶段 2 透传给所有 Subagent

## 终止条件

1. `.xmind` 已生成
2. `workflow.md` 已生成（记录本次执行流程 + 澄清决策 + 风险点）
3. coverage_manifest.json 强制校验通过
4. 覆盖自检通过
5. 最终回复已包含文件路径和覆盖统计
